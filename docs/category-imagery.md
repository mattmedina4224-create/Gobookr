# Homepage category imagery

Six AI-generated general marketing images illustrate barbers, hairstylists, nail artists, tattoo artists, lashes/brows, and massage therapists. They are never attached to named pros, fabricated reviews, or profile portfolios. Real profile photos continue to come from existing uploads.

The built-in image-generation tool produced the original square PNGs. Project versions are WebP assets, resized proportionately to 720 × 720 for the web, with no composition changes. Original outputs remain in the generating workspace. Images lazy-load below the hero and reserve layout space.

## Placement and behavior

A photo row sits between the existing homepage hero and the real-professional cards. It uses three desktop columns (two rows), two tablet columns, and horizontal swipe cards on narrow screens. Barbers come first. Each photo links to the corresponding professional category; the shared lashes/brows card has two distinct category links. “All specialties” opens the existing catalog. These versioned assets can be swapped independently for future visual experiments.
