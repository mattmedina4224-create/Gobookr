# Search weights

- Explicit service match: 120
- About Me / bio: 85
- Professional name or handle: 60
- Workplace: 45
- Broad professional category: 25

Profile quality adds less than one total point and therefore acts only as a tie-breaker. The current SQL quality signals are verified license, profile photo, substantive bio, at least one service, and a booking URL. Distance remains the next sort key in the public search route.
